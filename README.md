# YouTube без рекламы — модуль для Shadowrocket

Убирает рекламу в приложениях **YouTube** и **YouTube Music** на iPhone и iPad.
Вся обработка выполняется на самом телефоне, и трафик **не уходит на сторонние
серверы**.

В основе лежит модуль [Maasea/sgmodule](https://github.com/Maasea/sgmodule)
(Apache-2.0). Его код используется без изменений, но запускается внутри
защитной обёртки **yt-guard**: она разрешает скриптам обращаться только
к серверам Google/YouTube.

## Установка

1. Shadowrocket → **Настройки → Модули → +** (вверху справа) → вставьте ссылку:

   ```
   https://raw.githubusercontent.com/pmmodlin/sr-youtube/main/YouTubeAds.sgmodule
   ```

2. Включите MITM, если он ещё не включён: **Настройки → HTTPS-расшифровка
   (MITM)** → включить → **Сгенерировать новый CA-сертификат** → установить
   профиль в «Настройках» iOS → **Основные → Об этом устройстве → Доверие
   сертификатам** → включить доверие для сертификата Shadowrocket.
3. Полностью закройте YouTube (смахните из переключателя приложений) и
   откройте заново.

> Модуль подключается по ветке `main`, а сам он ссылается на скрипты по тегу
> версии (например `v1.0.0`). Поэтому код, который реально выполняется у вас,
> меняется только с выходом новой версии модуля. Он не может незаметно
> подмениться в ветке.

## Настройки

Чтобы их изменить, нажмите на модуль в списке модулей Shadowrocket.

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `Скрыть_кнопку_загрузки` | `true` | убирает кнопку «+» (загрузка видео) с нижней панели |
| `Скрыть_кнопку_клипов` | `true` | убирает кнопку клипов (иммерсивный режим) |
| `Скрыть_вкладку_Shorts` | `false` | убирает вкладку Shorts |
| `Перевод_субтитров` | `off` | автоперевод субтитров: код языка Google Translate (`ru`, `en`, `uk`…) или `off` |
| `Режим_отладки` | `false` | подробные логи в журнале Shadowrocket |

## Как это работает

Реклама в YouTube приходит не с отдельных рекламных доменов, а **внутри
обычных ответов API** в формате protobuf. Поэтому блокировка по DNS или по
доменам здесь не работает. Модуль расшифровывает (MITM) только два адреса:
`youtubei.googleapis.com` и `*.googlevideo.com`, и переписывает ответы прямо
на телефоне:

| Запрос | Что делает скрипт |
|---|---|
| `youtubei/v1/player` | удаляет рекламные вставки до и во время видео, включает фоновое воспроизведение и «картинку в картинке» |
| `browse`, `next`, `search`, `guide` | удаляет рекламу и промо из ленты, рекомендаций и поиска, скрывает кнопки по настройкам |
| `reel/reel_watch_sequence` | удаляет рекламу между Shorts |
| `get_setting`, `config`, `get_watch`, `log_event` | служебная подстройка, чтобы приложение не заметило подмену |
| `googlevideo.com/initplayback` | см. «Onesie» ниже |

Ещё модуль **запрещает QUIC** (HTTP/3 по UDP) для этих доменов. MITM работает
только с TCP. Если приложение уйдёт на QUIC, трафик пройдёт мимо скриптов, и
реклама вернётся.

### Onesie и отличие от оригинала

Новые версии YouTube получают видео и рекламу одним зашифрованным потоком
(«Onesie»). На телефоне его не разобрать. Поэтому оригинальный скрипт Maasea
перенаправляет такой запрос на свой сервер `init-stream.maasea.workers.dev`
(Cloudflare Worker) и передаёт в адресе **ключ клиента Onesie и исходный адрес
запроса**.

Здесь это запрещено. Когда оригинал пытается сделать такое перенаправление,
yt-guard:

1. блокирует его и пишет в журнал `[yt-guard] заблокировано: …`;
2. отвечает приложению пустым ответом;
3. стирает закешированный ключ Onesie.

После этого приложение запрашивает обычный `youtubei/v1/player`, а его скрипт
чистит локально.

**Цена:** иногда видео стартует чуть дольше. Если YouTube когда-нибудь
полностью откажется от `player`, реклама в роликах может начать проскакивать.

### Что именно ограничивает yt-guard

- Скрипт запускается только на хостах из `[MITM]` этого модуля.
- `$httpClient`, `$task`, `fetch` и `$done({url})`, а также заголовок `Location`
  пропускаются только к `googlevideo.com`, `youtube.com`, `googleapis.com`,
  `ytimg.com`, `ggpht.com`, `gstatic.com` (и их поддоменам).
- `XMLHttpRequest`, `WebSocket`, `EventSource`, `Image`, `importScripts` и
  `navigator.sendBeacon` запрещены полностью.
- Подмена действует и через параметры функции, и через глобальный объект.
  Поэтому обход вида `Function("return this")()` тоже не срабатывает.

Обёртка проверяется тестами в [`tools/verify.mjs`](tools/verify.mjs).

## Что вы доверяете и кому

- **Коду Maasea**: он видит расшифрованный трафик YouTube, включая заголовки
  авторизации. Он лежит в [`upstream/`](upstream/) ровно в том виде, в каком
  опубликован автором. Сверить можно так: sha256 файлов записан в
  [`upstream.lock.json`](upstream.lock.json) вместе с коммитом.
- **Этому репозиторию**: обёртка, сборка и модуль. Собранные файлы в
  `Script/` можно воспроизвести у себя командой `node tools/build.mjs --check`.
- **Тегу версии**: тег в git технически можно передвинуть. Если вы не
  доверяете владельцу репозитория, сделайте форк и подключайте модуль из него.

## Структура репозитория

```
YouTubeAds.sgmodule        готовый модуль (собирается, вручную не править)
Script/Youtube/*.js        скрипты Maasea внутри yt-guard (собираются)
src/YouTubeAds.sgmodule    шаблон модуля с пояснениями — правьте здесь
tools/guard-template.js    обёртка yt-guard
tools/config.json          версия, репозиторий, разрешённые хосты
tools/build.mjs            сборка (без сети)
tools/verify.mjs           тесты
tools/update-upstream.mjs  загрузка новой версии Maasea
upstream/                  оригинальные файлы Maasea на закреплённом коммите
upstream.lock.json         коммит Maasea и sha256 его файлов
```

## Обновление

Новые версии Maasea **не подтягиваются автоматически**. Раз в неделю
GitHub Actions проверяет оригинал и открывает issue, если там что-то изменилось.

```bash
node tools/update-upstream.mjs <sha-коммита-Maasea>   # скачать в upstream/
git diff upstream/                                     # посмотреть, что изменилось
node tools/verify.mjs                                  # тест №2 упадёт, если в коде появились новые внешние адреса
```

Если всё в порядке:

1. увеличьте `version` в `tools/config.json` (например `v1.0.1`);
2. `node tools/build.mjs && node tools/verify.mjs`;
3. закоммитьте, поставьте тег, совпадающий с `version`, и запушьте:

   ```bash
   git tag v1.0.1 && git push && git push --tags
   ```

Если Maasea изменил модуль (шаблоны запросов, аргументы, `[MITM]`), тест
«шаблоны совпадают с модулем Maasea» упадёт. Тогда перенесите изменения в
`src/YouTubeAds.sgmodule` вручную.

## Если реклама всё равно есть

- Проверьте, что MITM включён и сертификату **доверяют** (п. 2 установки).
- Закройте приложение полностью и откройте заново. Ответы YouTube частично
  кешируются.
- Включите `Режим_отладки` и посмотрите журнал Shadowrocket.
- Проверьте, что другой модуль или правило не пропускает UDP 443 для
  `googlevideo.com` раньше, чем это делает этот модуль.
